# Security Policy

## Supported versions

No SDK version has been published yet. Supported versions will be listed here with the first release.

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/cuppasoft/justdeploy-sdk/security/advisories/new). Do not disclose credentials, private keys, tokens or customer data in a public issue.

Include the affected package and version, impact, reproduction steps and any suggested mitigation. We will acknowledge the report and coordinate disclosure through the private advisory.
